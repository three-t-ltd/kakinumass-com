START WITH A SKETCH01 / 03

01 / SKETCH

図面の前に、
会話がある。

手書き図には、形状や寸法だけでなく、角度、部品の分割、角の形状、取り付けに関する確認が書き込まれています。

描かれている線をそのまま加工するのではなく、どこに指定があり、どこを相談できるのかを整理する。DFMは、この確認から始まります。

  • 角度に指定があるか
  • 部品を分け、溶接する構成でよいか
  • 角の形状や取り付け方法をどうするか

MAKE IT VISIBLE02 / 03

02 / 3D CAD

立体にして、
認識をそろえる。

スケッチの形を、奥行きのあるモデルへ。上面と側面のつながり、傾斜した面、開口部、下部のフランジを、立体として確認できます。

平面の線だけでは伝わりにくい形状も、視点を変えて共有することで、設計と加工の間の認識をそろえやすくなります。

  • 上面・側面・傾斜面のつながり
  • 開口部の形状と位置
  • 下部のフランジと取り付けの関係
設計・3DCADについて

FROM DRAWING TO REALITY03 / 03

03 / PRODUCT

画面の中の形を、
実物のカタチへ。

製品写真には、立体化したカバーの外形と開口部、端部のフランジ、部材をつなぐ接合箇所が見えます。

設計で考えた部品の構成が、実物のどの部分につながっているか。手書き図、3DCAD、製品を見比べると、その関係がわかります。

  • スケッチから引き継がれた外形
  • 立体モデルと実物の開口部
  • 面のつなぎ目と接合箇所

材質・仕上げの最終仕様、製作数量、納期、加工精度は、この事例では掲載していません。
